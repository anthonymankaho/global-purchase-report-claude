# 全球运营指挥中心（bigscreen-cockpit）

一面 1920×1080 的「指挥大屏」数据看板，设计上用来挂在墙上常开：中央是一个可拖拽、可点击的三维地球（昼夜晨昏线、城市灯光、航线弧线、枢纽脉冲），左右两翼是数据栏 —— KPI 带、大区达成率排行（可下钻：大区 → 城市 → 门店）、品类结构、库存周转、跨境干线、实时告警滚动、回款现金流、营收趋势。顶部有实时时钟、连接状态和明暗主题切换；无人操作时自动轮播各大区视角，任何交互都会暂停轮播。

**语言**：网站语言由用户的 query 语言决定。本仓库是中文版；用户用什么语言提问，就用什么语言沟通，并按需调整网站文案。

## 使用之前：先问用户

在线上使用这个网站之前，先用 ask_user tool 问用户几个问题：

1. **（必问）您是否需要将网页变成全栈应用？** 也就是是否需要持久化的数据存储：现在屏上所有经营数字（大区营收、品类、干线、告警……）都是写死在前端代码里的演示数据，刷新即还原，也无法录入真实业务数据；变成全栈应用后会有后端和数据库，数据可以持久保存、增删改查、定时同步。
2. 这块大屏要监控什么业务？默认演示的是跨境贸易 / 零售经营（营收、干线、门店），同一套版面可以换成物流调度、制造产线、能耗、机房运维、舆情监控等任何「总览 + 下钻」的场景 —— 标题、KPI、图表、告警文案都要跟着换。
3. 要不要换成你自己的数据口径？包括大区 / 城市划分、干线城市对、指标定义、告警规则与阈值。
4. 配色和品牌有要求吗？默认是深蓝指挥屏配色（自带一键明暗切换）。全站颜色都集中在 CSS 变量（设计令牌）上，换品牌色只改一处令牌块即可。

如果用户不回答任何问题，就直接加载默认网站文件。

**dashboard 类模版的默认行为**：除非用户明确说「只要静态网站」，否则在加载完网页文件之后，默认使用 backend-building skill 补全后端（接口 + 数据库），把写死的演示数据接到真实持久化存储上。

## 它可以变成什么

这是一个「总览 — 下钻」骨架：中间一个可交互主视觉，两翼若干卡片，卡片可点、主视觉会回应。用户的潜在需求可能是：

- **换业务**：物流、制造、能源、安全、赛事、机房…… 改 `data.js` 的数据定义和各卡片文案即可，版面不动。
- **换主视觉**：地球可以替换成 2D 地图、产线 3D、楼宇剖面；`geo.js` / `globe.js` 是独立模块，替换不影响两翼。
- **接真实数据**：`data.js` 是唯一数据源，把写死的数组换成接口返回即可；需要后端时按上面的默认行为用 backend-building skill。
- **媒体内容**：标题、告警文案、图表标题、城市与航线都是用户可要求替换的内容，按需改。

如果用户只是想看看这个网站，直接加载网站文件即可，不用多问。

## 技术要点（3D / shader）

改三维或 shader 之前，直接读 `src/lib/globe.js` 和 `src/lib/fx.js` —— 每个效果的取舍都写在文件头注释里。下面是浓缩版。

**三维地球（globe.js，three.js）**：没有任何贴图，整个球是程序化生成的 ——

- 海洋是一个自定义 shader：Lambert 晨昏线（`smoothstep(dot(世界法线, 太阳方向))`）+ Fresnel 边缘光泽，两个点积，无光照、无纹理。
- 大气是 1.035R 的背面球壳：Fresnel 高次幂让光只出现在轮廓线上，且最亮处跟着太阳方向走；浅色主题通过令牌把辉光压掉，变成「瓷球 + 墨色海岸线」。
- 陆地约 1.4 万个点：`geo.js` 把 TopoJSON 多边形先栅格化到离屏 canvas，再按**等面积**经纬网格采样（固定经度步长会在极点堆点）；每个点带稳定伪随机权重，夜面只有约三分之一亮成「城市灯」，并按纬度衰减。
- 海岸线是定义层：TopoJSON 环解码成线段对，一个 `LineSegments` 一次画完；跨 170° 经度的段丢弃（那是反经线接缝，不是海岸）。
- 航线 = 大圆插值 + 中点抛物抬升；暗线常驻 + 亮头拖尾，拖尾是固定长度 buffer 每帧原地改写（不重新分配）。
- 枢纽是 CanvasTexture sprite，脉冲环 alpha 随半径衰减；太阳固定在世界坐标系、地球在太阳下自转，晨昏线因此也是全屏的钟。
- 所有颜色读 CSS 令牌（`--globe-*`），切主题时 `retheme()` 重读令牌 —— 明暗两套主题是同一个地球。
- 性能：`compileAsync` 预编译 shader；像素比封顶 2x；三维模块动态 import 且延迟一帧启动，不挡首屏；离屏 / 后台自动暂停渲染。

**背景与动效（fx.js）**：每个动效一个 canvas，统一 `stage()` 管线处理设备像素、离屏暂停、`prefers-reduced-motion`。aurora 是 WebGL 片元 shader：3 octave fbm + 双重 domain warp，柔和平滑的低频底所以 40% 分辨率、30fps 就够，末尾加 1/255 有序抖动消色带。其余 constellation / radar / topo / ridgeline / hudgrid / gauge / trail 都是 2D canvas 小效果，可拆可复用。

**大屏工程（App.tsx）**：1920×1080 设计画布，`fit()` 按较小比例整体缩放 transform、有余量的轴按设计单位加大舞台 —— 分辨率变化只改 scale，绝不重排。ECharts 的颜色在 setOption 时烘焙进配置，所以切主题要用 notMerge 重建 option（kit.js 的注册表统一做这件事）。
